\-----------What the Program Does-----------



This app lets the user create colors by adjusting red, green, and blue values. The app shows the current RGB values, displays the color as a hexadecimal value, and changes the screen background to match the selected color. The user can save colors to a list and tap a saved color to load it again. The text changes between light and dark colors to remain readable against the background.



\-----------How to Use the Program------------



1\. Open the app.

2\. Drag the Red, Green, and Blue sliders. Each value can be set from 0 to 255.

3\. Look at the labels and hexadecimal value to see the current color.

4\. Tap 'Save Color' to add the current color to the Saved Colors list. The sliders and background reset to black.

5\. Tap a color in the Saved Colors list to load it. The sliders, hexadecimal value, and background update to that color.
